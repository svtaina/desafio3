# Desafio 3 – Perfil de Usuário com Banco de Dados

## Descrição
Nesta atividade, foi desenvolvido um sistema de login utilizando PHP e MySQL. O sistema permite que o usuário entre com seu nome e senha cadastrados no banco de dados e escolha uma cor de fundo para sua página de perfil.

## Objetivo
Praticar o uso de sessões em PHP, formulários, conexão com banco de dados e consultas SQL, permitindo controlar o acesso à página de perfil.

## Arquivos do projeto
- **15d_login.php:** formulário de login, consulta os dados do usuário no banco e salva o nome e a cor escolhida na sessão.
- **15d_perfil.php:** verifica se o usuário está logado e exibe uma mensagem de boas-vindas com a cor de fundo escolhida.
- **15d_logout.php:** encerra a sessão e redireciona o usuário para a página de login.

## Banco de Dados
- Banco: `exercicio`
- Tabela: `usuarios`

Os dados utilizados são os mesmos cadastrados na atividade anterior.

## Tecnologias utilizadas
- HTML
- CSS
- PHP
- MySQL

## Resultado
O sistema permite realizar login, escolher uma cor de fundo para o perfil, visualizar uma mensagem de boas-vindas e sair da conta com segurança por meio do encerramento da sessão.
